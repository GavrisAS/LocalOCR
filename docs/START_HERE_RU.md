# LocalOCR — Windows Evaluation (не production)

1. Скачайте ZIP `LocalOCR-vMAJOR.MINOR-windows-x64.zip` и его `.sha256` со страницы
   этого prerelease. SHA256 также указан в release-manifest.json; его можно сверить
   средством проверки хешей вашей Windows. Распакуйте ZIP **целиком** в новый доступный
   для записи каталог (например, Документы/LocalOCR), не в Program Files.
2. Запустите `LocalOCR/LocalOCR.exe`. Python, uv, Codex, Excel и права администратора
   не нужны. Не запускайте EXE внутри ZIP. При обновлении используйте новую папку.
3. Нажмите «Полный интерфейс / настройки сервера…». Полный интерфейс также открывает
   `LocalOCR-full-gui.cmd` рядом с EXE. Выберите OpenWebUI Chat Completions,
   OpenWebUI Ollama Proxy либо Direct Ollama; введите актуальный URL, точный Model ID
   GLM-OCR или DeepSeek-OCR из списка вашего сервера и токен, если он нужен серверу.
   Нажмите «Проверить подключение». Модель и адрес автоматически не выбираются.
   TLS/системный proxy настраиваются в полном GUI; токен хранится открытым текстом
   в config.json рядом с EXE. Не отправляйте этот файл другим людям.
4. Выберите папку с пробным изображением. При желании включите «Сохранять частичные
   данные (fail-soft)» — по умолчанию выключено. Настройка сохраняется. Начните
   обработку. Исходные изображения сохраняются. Существующие XLSX не перезаписываются.
5. Откройте `results/` рядом с исходными изображениями кнопкой приложения.
   PARTIAL/REVIEW — черновик: сверяйте цифры и размещение с оригиналом. Откройте лист
   «Проверка»; наблюдения могут быть на «Распознанный текст» или «Неразмещённые данные».
   Непустой XLSX не доказывает точность или геометрию таблицы.
6. Попробуйте «Остановить», дождитесь остановки, повторите обработку. Завершённые
   результаты с подтверждённой identity могут возобновляться без OCR; незавершённые
   книги не публикуются. summary/report и jobs.jsonl находятся в results/.
7. config.json, localocr.log, diagnostics/ и work/ создаются рядом с EXE. Они могут
   содержать личные пути и настройки. Возвращайте только обезличенные статусы,
   версию и описание проблемы; не отправляйте токены, конфиги, документы, OCR/XLSX.

Lite требует сеть до явно выбранного сервера. Embedded runtime и веса **не входят**;
GPU/CPU без сервера в этом ZIP не работают. Автоматической загрузки модели нет.
SERVER_PENDING, EMBEDDED_PENDING и MANUAL_GUI_PENDING сохраняются. В CI проверяются
синтетический loopback HTTP, XLSX readback и startup обеих оболочек; настоящие
OpenWebUI GLM/DeepSeek и ручная приёмка GUI ещё не подтверждены. Проверка 1000
реальных OCR и промышленная готовность не заявляются. PRODUCT_RELEASE=NO_GO.
